UI / UX

The application should feel like a premium, modern B2B SaaS product.

It should be:

Clean
Professional
Intelligent
Trustworthy
Data-rich
Efficient
Enterprise-ready
Visual principles

Prioritize:

Strong typography hierarchy
Consistent spacing
Good information density
Clear primary actions
Subtle borders
Restrained shadows
Consistent status colors
Reusable components
Clear visual hierarchy

Avoid:

Generic dashboard templates
Excessive gradients
Excessive rounded cards
Huge empty spaces
Random colors
Excessive animations
Gimmicky AI visuals
Clutter
Placeholder-looking UI
AI-generated information

AI output should feel structured and trustworthy.

Examples:

Summaries
Insights
Decisions
Suggested actions
Generated tasks

Use subtle visual treatment to distinguish AI-generated information where useful.

Do not put an "AI" badge everywhere.

States

Important screens must handle:

Loading
Empty
Error
Processing
Completed
Long content
Large datasets

Empty states should tell the user what they can do next.

Responsive

The frontend must work properly on:

Desktop
Laptop
Tablet
Smaller screens

Pay particular attention to:

Navigation
Tables
Filters
Meeting detail
Transcript
Tasks
Modals/dialogs

Do not simply shrink the desktop layout.

UX principle

Always ask:

"What does the user need to understand or do next?"

The UI should make the answer obvious.

The product should feel cohesive across every screen, even if different parts were implemented at different times.
